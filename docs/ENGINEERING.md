# The engineering

One operator. Three knobs.

```
P / G → Q
```

| workshop | V | G | θ |
|---|---|---|---|
| logic | listed truth values | NOT/AND/OR from maps into V | designated set; leave-V |
| algebra | listed Z/n or named Q | + × inverses that exist | no unit; unlistable; no root *here* |
| calc | Q-pairs (jet when paid) | isolate, Leibniz, quot, rate | dead isolator; leftover listed |

Same audits everywhere:

- close-test before a law
- grow V before identity of two ops
- leftover stays on the page
- μ to change V; no teleport
- work on a ledger

What the three workshops share that textbooks split:

- a letter is a hole (algebra) / an isolator (calc) / a value (logic)
- agreement on a small V is not one op
- ∞ is never an inhabitant
- solving / differentiating / proving are searches and extracts on a cut
