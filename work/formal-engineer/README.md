# Formal engineer

Stipulated V. Declared G. Finite θ.

This repo is a workshop, not a church. It enumerates every *computable*
combination of operations that stays inside a listed alphabet, prices
what happens when you pretend the alphabet is infinite, and names the
ghosts: outputs treated as primitive containers or as the cause of the
ops that produced them.

```
python -m engineer            # all demos
python -m engineer enum       # combinatorics on a V
python -m engineer infinity   # cost of unlistable V
python -m engineer introduce  # change a knob, laws flip
python -m engineer ghosts     # reifications with receipts
python -m engineer poles      # singularities as θ
python -m engineer census     # every map V^k→V on V2 and V3
```

Dogmatic technician: inherit the primitives, defend the singularities,
call a new cut a toy.

Formal engineer: name the knobs, enumerate what closes, register μ
when V changes, put work on a ledger.
