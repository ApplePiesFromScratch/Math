# Teacher notes

Same numbers as Calc I on polynomials and rationals. Different bookkeeping.

| standard | here |
|---|---|
| y = f(x), x independent | two readings, isolate who you name |
| f'(x) | rate(f, x) |
| chain rule | rate(q,y)·rate(y,x) |
| product rule | Leibniz mix, not a new law |
| limit definition | dropped; leftover of fd is named when you use fd |
| vertical asymptote | θ |
| related rates chapter | same kernel, second reading |
| implicit d/dx | constraint channel dead |

When a student writes dy/dx, ask: which two channels, and did a third just cancel?

Do not say this is easier. Say the hidden assumptions are now knobs.
